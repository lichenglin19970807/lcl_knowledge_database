# 阵容

## 岚鸟（翼）
冰愿力
- **抵抗面**：草、虫、武
- **被克制面**：冰、电
技能：
1. 龙卷风（翼·物攻）— 打击面：草、武、虫
2. 筛管奔流（草·物攻）— 打击面：水、地、光
3. 撕咬（恶·物攻）— 打击面：毒、萌、幽
4. 水刃（水·物攻）— 打击面：火、地、机械

## 黑猫巫师（普通）
水愿力
- **抵抗面**：幽
- **被克制面**：武
技能：
1. 羽化加速 — 辅助
2. 乱打（普·魔攻）— 无克制
3. 午夜噪音（幽·魔攻）— 打击面：光、幻、幽
4. 彗星（普·魔攻）— 无克制

## 绒光优优（地 + 光）
火愿力
- **抵抗面**：普通、火、电、毒、翼、恶、幻（均为0.5×，广抗性）
- **被克制面**：草(3×)、水、冰、武、幽、机械
技能：
1. 引燃 — 状态
2. 天光（光·魔攻）— 打击面：幽、恶
3. 热砂（地·魔攻）— 打击面：火、冰、电、毒
4. 硬化 — 防御

## 奇丽花（草）
水愿力
- **抵抗面**：水、光、地、电
- **被克制面**：火、冰、毒、虫、翼
技能：
1. 花炮（草·魔攻）— 打击面：水、地、光
2. 叶绿光束（草·魔攻）— 打击面：水、地、光
3. 光能聚集 — 增益
4. 纤维化 — 防御

## 窃光蚊（光 + 恶）
恶愿力
- **抵抗面**：幻、恶（强抵抗）
- **被克制面**：草、光、虫、武、萌
技能：
1. 力量增效 — 增益
2. 先发制人（普·物攻）— 无克制
3. 蝙蝠（恶·物攻）— 打击面：毒、萌、幽
4. 光之矛（光·物攻）— 打击面：幽、恶

## 落陨星兔（幻 + 幽）
武愿力
- **抵抗面**：普通、毒、幻、武(0.25×强抵抗)
- **被克制面**：幽(3×)、光、恶
技能：
1. 魔法增效 — 增益
2. 嗜痛 — 防御
3. 恐吓 — 削弱
4. 坍缩（幻·魔攻）— 打击面：毒、武
