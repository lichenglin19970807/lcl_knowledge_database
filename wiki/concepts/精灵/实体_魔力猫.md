# 魔力猫

| 字段 | 值 |

| **编号** | #004 |
| **属性** | 草 |
| **种族值**（613） | 精力 108 / 物攻 109 / 魔攻 109 / 物防 81 / 魔防 151 / 速度 55 |

## 特点分析
