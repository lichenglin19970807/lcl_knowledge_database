# 概念：确一

## 定义

**确一**（Guaranteed OHKO）：在 A 精灵对阵 B 精灵时，**A 的速度比 B 快**，A 使用某个技能，**在 B 不防御（即不切换、不使用防御类招式）的情况下，A 能够一击将 B 击杀（HP 归零）**。

## 成立条件

| 条件 | 说明 |
|------|------|
| **速度优势** | A 的速度 > B 的速度（或 A 先手） |
| **技能选择** | A 使用某特定攻击技能 |
| **无防御假设** | B 不切换宠物、不使用护盾/减伤/闪避类技能 |
| **伤害门槛** | 该技能造成的伤害 ≥ B 当前 HP |

## 与相关概念的区别

| 概念 | 区别 |
|------|------|
| **确一** | 先手 + 无防御条件下一击必杀 ✅ |
| **概率一** | 伤害有浮动范围，有一定概率一击但非100% |
| **两回合击杀** | 需要两次攻击才能完成击杀 |
| **后手确一** | A 速度慢于 B，需承受一次攻击后反杀 |

## 应用场景

- **选宠阶段评估**：判断我方精灵是否能确一对方关键目标
- **换宠决策**：如果当前精灵无法确一对方，考虑换入能确一的精灵
- **配招选择**：为覆盖常见目标的确一需求配置对应技能
- **属性克制利用**：克制关系（×2 或 ×3）是达成确一的重要途径

## 计算要素

影响是否确一的关键变量：

1. **攻击方的物攻/魔攻数值** + 技能威力
2. **属性克制倍率**（×0.5 / ×1.0 / ×2.0 / ×3.0）
3. **防御方的物防/魔防数值**
4. **双方等级差**
5. **伤害浮动随机因子**
6. **B 的当前/最大 HP**

> 当伤害期望值远高于 B 剩余 HP 时称为「硬确一」；当伤害期望值处于临界区间（依赖高 roll 才能确一）时称为「软确一」。
