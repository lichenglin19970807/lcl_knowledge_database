# 水泡盾

## 基本信息

| 字段 | 值 |
|------|-----|
| **属性** | 水 |
| **能耗** | 2 |
| **类型** | 防御 |
| **威力** | 无 |
| **效果** | 减伤80%，应对攻击：自己获得魔攻 +70% |

> 高额减伤 + 攻击增益二合一。配合水泡壳特性"缩壳"（防御技能能耗-2）实际仅耗1点，性价比极高。
