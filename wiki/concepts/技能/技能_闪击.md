# 闪击

## 基本信息

| 项目 | 值 |
|------|-----|
| **属性** | 翼 |
| **类型** | 物攻 |
| **基础威力** | 60 |
| **最大威力** | **200** |
| **能耗** | 4 |

## 效果

> ✦ 造成物伤，速度比敌方越高，本次技能威力越高。

## 威力随速度差变化表

| 己方速度 - 敌方速度 | 实际威力 |
|---------------------|----------|
| < 0（低于或相同） | 60 |
| 0 ~ 14 | 100 |
| 15 ~ 29 | 130 |
| 30 ~ 44 | 140 |
| 45 ~ 59 | 150 |
| 60 ~ 74 | 160 |
| 75 ~ 89 | 170 |
| 90 ~ 104 | 180 |
| 105 ~ 119 | 190 |
| 120 ~ 134 | 195 |
| ≥ 135 | **200（封顶）** |

### S2赛季调整

速度阈值调整，最高仍为200封顶。

> 高速翼系核心输出——速度领先135以上即可打满200威力，4能耗性价比极高。适合高速翼系精灵（如圣羽翼王、皇家狮鹫）作为主力物攻手段。
