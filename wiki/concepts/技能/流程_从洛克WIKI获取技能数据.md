# 从洛克 WIKI 获取技能数据

## 数据源

| 项目 | 值 |
|------|-----|
| 站点 | BWIKI rocom（洛克王国：世界） |
| URL 模板 | `https://wiki.biligame.com/rocom/{技能名称}` |
| 编码 | UTF-8 |
| 渲染方式 | WebFetch 可直接解析（无需浏览器自动化） |

## 输出格式（6 项）

```
## {技能名称}

- **属性**：{属性名}
- **能耗**：{PP值}
- **类型**：{攻击/防御/状态/物攻/魔攻}
- **威力**：{数值 / 无}
- **效果**：{效果描述}
```

## 执行步骤

1. 构造 URL：`https://wiki.biligame.com/rocom/{URL编码的技能名称}`
2. 使用 WebFetch 抓取，prompt 要求提取：**名称、属性、能耗、类型、威力、效果描述**
3. 按 5 项格式输出（**不抓取**"可学会此技能的精灵"列表）

## 注意事项

- rocom = 洛克王国：世界（手游版），与端游技能数据可能不同
- 技能页面是单技能详情页，每个 URL 对应一个技能
- 类型字段可能显示为"物攻"/"魔攻"/"攻击"/"防御"/"状态"等，原样保留
