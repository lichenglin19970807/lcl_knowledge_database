# 山火

## 基本信息

| 字段 | 值 |
|------|-----|
| **属性** | 火 |
| **能耗** | 3 |
| **类型**：物攻 |
| **威力**：15（起始） |
| **效果** | 造成物伤，每使用 1 次其他火系技能，本技能威力永久翻倍 |

> 火红的烈焰从地底最深处向外迸发。15→30→60→120，指数级成长的核弹。
