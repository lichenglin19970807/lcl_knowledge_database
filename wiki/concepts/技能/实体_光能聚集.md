# 光能聚集

## 基本信息

| 字段 | 值 |
|------|-----|
| **属性**：草 |
| **能耗**：7 |
| **类型**：魔攻 |
| **威力**：100（起始） |
| **效果**：造成魔伤，每次使用其他草系技能后，本技能威力永久 +60 |

> 与火系山火对称的草系核弹。100→160→220→... 几次草技铺垫后一击致命。
