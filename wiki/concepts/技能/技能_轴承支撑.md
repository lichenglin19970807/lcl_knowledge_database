# 轴承支撑

## 基本信息

| 项目 | 值 |
|------|-----|
| **属性** | 机械 |
| **类型** | 状态 |
| **威力** | 0 |
| **能耗** | 3（被动额外-1 = **实际2**） |

## 效果

> 本技能被动额外-1能耗；两侧技能能耗-1，传动1。

## 效果详解

| 效果类型 | 描述 |
|----------|------|
| **自身减耗** | 使用时被动额外减少1点能耗（实际消耗2点） |
| **两侧减耗** | 位于中间位置时，左右两侧相邻技能各减少1点能耗 |
| **传动1** | 触发传动机制 |

> 放在技能栏中间（2号位）时收益最大化：自身实耗2 + 左右各减耗1。
